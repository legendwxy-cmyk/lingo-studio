Lingo（macOS 原生桌面版 v1.3.3）安装与使用说明
==============================================

1. 安装步骤
   - 双击打开 Lingo-macOS.dmg
   - 将「Lingo.app」拖入右侧的「Applications（应用程序）」文件夹
   - 在「应用程序」或启动台中打开「Lingo」

2. 首次打开如遇 macOS 安全提示与权限开关
   - 若提示「无法验证开发者」，先点「完成」，再前往「系统设置 -> 隐私与安全性 -> 安全性」点击「仍要打开」并输入开机密码即可永久放行
   - 或在「应用程序」里右键点击「Lingo.app」-> 选择「打开」-> 再次点击「打开」
   - 顺手确认开启「本地网络」（供同 Wi-Fi 平板连接）与「麦克风」（供网页跟读录音）权限

3. 全程免命令行启动与原生桌面控制台（4 大面板 + 三套 3D 机壳皮肤）
   - 首次打开 Lingo.app 时全程在后台自动准备运行环境并展示原生进度浮窗，无需弹出黑色命令行窗口，准备完成后自动关闭浮窗并直接打开 Lingo 原生桌面窗口
   - 顶部支持切换「柑橘旋钮机 / 薰衣草工坊 / 奶油陶瓷台」三套皮肤，并在系统右上角菜单栏常驻快捷图标
   - 「服务总览」：一键启停/重启学习机服务、设置监听端口、开启「局域网共享」（拨开开关即刻在下方显示完整局域网网址与「复制地址 / 立即应用并重启」按钮）、访问口令与自动启动
   - 「环境与依赖」：实时检测 Python 3.10–3.12 / 虚拟环境 / FFmpeg / Faster-Whisper，内置国内加速镜像，缺失一键全自动安装或修复
   - 「AI 模型」：内置 DeepSeek / OpenAI / 通义千问 / Groq / 硅基流动 / Gemini 预设，支持密钥脱敏保存与一键测速
   - 「运行日志」：实时查看服务与安装日志、关键词过滤与一键复制

4. 同一局域网用平板电脑（iPad / 安卓平板）或手机访问
   - 确认 Mac 与平板连接在同一个 Wi-Fi 下，且 Mac 端 Lingo 服务保持运行
   - 在「服务总览」打开「局域网共享」，直接查看下方显示的局域网地址（例如 http://192.168.1.28:8000）
   - 若服务已在运行中，点击地址旁的「立即应用并重启」使局域网生效
   - 在平板浏览器地址栏输入这串网址即可大屏同步精听与跟读，无需安装任何 App

5. 数据与无缝升级
   - 你的全部语料库、跟读录音、生词本、配置与 Whisper 缓存均独立保存在：
     ~/Library/Application Support/LingoReelStudio/
   - 从旧版本升级时直接覆盖安装 Lingo.app 即可自动继承全部历史数据并刷新最新界面。
